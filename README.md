# Почтовое отделение

Курсовой проект по МДК 05.02. Настольное приложение на C# и WPF для учёта клиентов, тарифов, почтовых отправлений и сопутствующих товаров. Включает базу Microsoft SQL Server, отчёты за период, роли оператора и администратора и встроенный REST API.

## Запуск

1. Установите Visual Studio с компонентом разработки классических приложений .NET и пакетом разработчика .NET Framework 4.7.2.
2. Создайте пустую базу PostOfficeDB в отдельном экземпляре SQL Server для учебного запуска. По умолчанию используется локальный .\SQLEXPRESS и проверка подлинности Windows. Учётная запись должна иметь право создавать таблицы и работать с ними.
3. Задайте переменные окружения POSTOFFICE_DEMO_ADMIN_PASSWORD и POSTOFFICE_DEMO_OPERATOR_PASSWORD для первого запуска. Используйте два разных пароля длиной от 12 символов. Для изменения сервера или базы задайте POSTOFFICE_SQL_SERVER и POSTOFFICE_SQL_DATABASE. При использовании аутентификации SQL Server задайте POSTOFFICE_SQL_USER и POSTOFFICE_SQL_PASSWORD.
4. Запустите Visual Studio из сеанса, в котором заданы переменные. Откройте WpfApp1.sln, соберите и запустите проект. При первом запуске приложение создаст таблицы и заполнит их учебными данными. Войдите как admin или operator с соответствующим паролем.

## Программный интерфейс

Интерактивная документация доступна по адресу http://localhost:5080/swagger. Спецификация OpenAPI доступна по адресу http://localhost:5080/swagger/v1/swagger.json. API слушает только localhost. Токены по умолчанию подписываются случайным ключом текущего сеанса. Чтобы ключ сохранялся между запусками, задайте собственное случайное значение через POSTOFFICE_JWT_SECRET.

Для самопроверки запустите WpfApp1.exe --selftest на демонстрационной базе с настроенными паролями. Результаты сохраняются в selftest.txt рядом с исполняемым файлом.
